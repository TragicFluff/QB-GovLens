# Finding the guidance that applies to this case

You have one tool, `search_guidance`, over three sources: the official Governance Guide (GG), the official Data Glossary (DG) and the GovLens rule specification (RS, tool documentation, not policy).

## Method

1. Read the analyst's facts. Write 2 to 4 searches, each aimed at one fact, not at the case in general. Good searches name the behaviour and the data field, for example:
   - "buyers in the same department buying the same category within a short period"
   - "seller limits quantity per cart, several orders on the same day"
   - "six-month spend limit per officer"
   - "Reason_For_Purchase vague or generic"
   - "Total_Amt_Payable includes GST and shipping"
2. Prefer GG passages for anything about what reviewers should check or what the limits are. Use DG only for what a field means. Use RS only to describe how the GovLens rule works.
3. Keep only passages that bear on a fact. Drop passages that merely share a keyword.

## Output

For each passage you keep: its exact citation ID in square brackets, one sentence on which fact it bears on, and whether it supports a split reading, a legitimate explanation, or only defines terms. Keep 3 to 6 passages. If nothing relevant is found for a fact, say so.
